# Repository Context

## What this repo does
This repository contains a browser-based Memory / Concentration card game. The app is implemented as a single HTML file with embedded CSS and JavaScript, and it lets the player:

- flip cards to find matching pairs
- choose between a 4x4 and 6x6 grid
- track moves and elapsed time
- rate performance with a star-based scoring display
- save best scores in local browser storage
- play with mouse or keyboard for accessibility

The goal is simple: match all pairs as quickly as possible with the fewest moves.

## What the project is called
The repo name is `memory-game-GHCP`.

- `memory-game` describes the actual app: a classic card-matching game.
- `GHCP` is most likely shorthand for GitHub Copilot, which is the coding environment/tooling context this project was created under.

So the full meaning is essentially: a memory game project created or developed in a GitHub Copilot-assisted workflow.

## Technologies used
- HTML for structure
- CSS for styling and responsive layout
- JavaScript for game logic and interactivity
- Local browser storage for persistence of best scores

## Main files
- `memory-game.html` — the complete game and UI
- `README.md` — quick usage and project overview
- `context.md` — repository context and meaning

## How to use it
Open `memory-game.html` in a browser and start playing. You can also serve the folder with a local web server if needed.

## Summary
This repo is a lightweight, dependency-free front-end game project designed to be easy to run, easy to understand, and easy to adapt for learning or demo purposes.
